# Travel Journal（远行手记）

一个会随四季变化、帮你随手记录并重新回到旅途现场的个人旅行日记。

单管理员的自托管站点：白天在路上二十秒记一条随手记，晚上一键整理成带开场、章节和照片的日记草稿，发布后是一篇有主题氛围、有当天路线回放的文章。

## 写作

- 日记可以先于旅行独立创建，也可以从旅行工作台进入或稍后归入旅行；支持草稿、发布、更新发布和撤回。
- 正文直接连续写：段落、小标题、引用和提示卡不弹窗，回车按普通输入换行，段首退格与上一组件合并。
- 29 种可视化内容块，覆盖正文、提示、清单、表格、同行者、地点、美食、住宿、交通、天气、图片组和明信片等旅行场景。
- 今日开场卡、章节节点和今日小结，城市、第几天、路线和花费从旅行工作台自动填。
- 日记模板可生成继续独立编辑的内容块；后续修改模板不会覆盖已写正文。
- 发布前可就地预览整篇文章，用的是和公开页面同一套渲染。
- 标题和 slug 可以留到发布前再补，停手自动保存；点进去看一眼就退出不会留下空记录。

## 照片

- JPEG / PNG / WebP 选择、拖放或粘贴上传，支持缩略图预览、多选插入、图注、封面、批量删除和拖拽排序。
- 选完立刻插入正文并显示上传进度，并发上传但保持挑选顺序，单张失败可重试。
- 照片本身也进 IndexedDB：断网拍照、浏览器被系统杀掉，重新打开照片还在，有网自动续传。
- 图片设置按「内容、版式、外观、图注」分组，配真实文章预览；只展示当前排版真正生效的设置。
- 五档宽度（小图、中等、大图、正文宽度、通栏出血）、九种画框、三档色调、三种悬停动效，全部纯 CSS 绘制。
- 十种多图排版：并排、网格、瀑布流、拼贴、杂志、故事流、错落画廊、轮播、胶片条、前后对比；灯箱支持同组翻页。

## 随手记

- 路上二十秒记一条：一句话、几张照片、一个地点。除了「属于哪次旅行」没有任何必填项。
- 晚上按「整理成日记」，当天碎片按时间变成一篇草稿；同一天可以整理多次，默认追加，也可以重新生成整篇。
- 完整离线队列：断网重试、刷新页面或上传中途恢复都只补齐未完成的部分，不会重复创建。
- 时间同时保存绝对时刻、当地日期、时区和 UTC 偏移，跨时区旅行不会落到错误的一天。
- 可选的 AI 整理：把碎片句子润色成段落，**只改文字不改结构**；没配 Key 或模型不可用时退回原文，整理照常完成。

## 旅行与地图

- 旅行、城市停靠点、行程管理；不再需要的旅行可以归档，也可以连同日记、随手记、照片整体删除。
- 分类预算、实际支出和超支汇总。
- 地点搜索、地图选点、逆地理编码、旅行路线和可筛选的城市足迹地图。
- 日记页附带当天路线，可以「回放这一天」，每个点带上当时写的话和拍的照片。

## 主题

- 六套系统主题（远行经典、复古、春夏秋冬），可跟随季节自动轮换，也可固定用某一套。
- 主题不只是配色：装饰、贴纸、分隔线、氛围层、区块皮肤和互动一起构成一套完整视觉。
- 可视化主题 DIY、JSON 导入导出，以及全站 / 旅行 / 单篇日记三级覆盖。

## 其他

- 单管理员登录、退出、修改密码和昵称。
- 公开首页、旅行列表和日记详情；桌面与手机响应式。
- 可「添加到桌面」的 PWA，离线仍能打开编辑器接着写。
